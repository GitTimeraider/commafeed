# Security Policy

## Reporting a Vulnerability

If you found a vulnerability that you deem too sensitive to disclose publicly in a Github issue, please create a private security advisory here: https://github.com/GitTimeraider/commafeed/security/advisories

If the vulnerability is in CommaFeed itself rather than in this fork's changes (the Docker image, entrypoint or CI), please also report it upstream: https://github.com/Athou/commafeed/security/advisories
